Meawfy Client is a zero-dependency Python SDK for `GET /internal/api/results.json` — the endpoint that powers meawfy.com's file search across MEGA, Dropbox, and Google Drive. It turns the endpoint's undocumented caps, silent parameter drops, and 200-on-error behaviour into things a program can branch on.

## Why a dedicated client?

The endpoint answers `200` to malformed requests, silently ignores unknown parameter names, falls through to the default when an enum value is capitalised, and stops paging at 10,000 rows without saying so. A bare `urllib` call or a `curl` command will not catch any of this.

Meawfy Client closes each trap before it becomes a bug in your code:

<CardGroup cols={2}>
  <Card title="Parameter Validation" icon="shield-check" href="/api/parameters">
    All 50 parameters are validated before the network call. Unknown names raise `UnknownParameter`; bad values raise `InvalidParameter`.
  </Card>
  <Card title="Echo Reports" icon="magnifying-glass" href="/concepts/echo-and-traps">
    Every response exposes an `EchoReport` that shows which parameters the index actually honoured, changed, or dropped.
  </Card>
  <Card title="Safe Paging" icon="arrow-right" href="/guides/paging-and-collecting">
    `iterate()` and `collect()` stop at the 10,000-row window instead of silently returning misleading results.
  </Card>
  <Card title="Rate Limiting" icon="gauge" href="/guides/rate-limiting">
    Sliding-window pacing at 120 req/min, automatic `Retry-After` handling, and an exposed `remaining` counter.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Get the code">
    Clone the repository or add it to your `PYTHONPATH`. Python 3.9+ and no dependencies beyond the standard library.

    ```bash
    git clone https://github.com/novodevo/meawfy-client.git
    cd meawfy-client
    ```
  </Step>
  <Step title="Run your first search">
    ```python
    from meawfy import MeawfyClient, Query

    client = MeawfyClient()
    envelope = client.search("periodic table", providers=["mega", "dropbox"], per_page=10)
    print(envelope.total, "results")
    for row in envelope.results:
        print(row.name, row.human_size)
    ```
  </Step>
  <Step title="Check the echo">
    ```python
    report = envelope.echo_report(envelope)
    if not report.ok:
        print("Parameters not honoured:", report.summary())
    ```
  </Step>
  <Step title="Explore guides and recipes">
    The [Recipes guide](/guides/recipes) covers eight ready-made query patterns from The Query Handbook. The [CLI reference](/cli/overview) documents every command available from `python -m meawfy`.
  </Step>
</Steps>

## Zero dependencies

Meawfy Client uses only the Python standard library: `urllib` for transport, `argparse` for the CLI, and plain strings for output. Python 3.9 or newer is all you need.
