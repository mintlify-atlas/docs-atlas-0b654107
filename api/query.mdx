The `Query` class is the single place where request parameters are validated and serialized. It accepts free text plus any of the 50 documented parameters, checks every value at construction time, and renders deterministically to a query string. Nothing about a `Query` changes after it is built — mutations produce a new object through `copy()`.

## Why validate before sending?

The endpoint answers `200` to malformed requests: an unknown parameter is silently ignored, `sort=Size` (wrong case) falls through to `relevance`, and a query longer than 200 characters is truncated without warning. `Query` turns each of these into a Python exception before any network call goes out.

```python
from meawfy import Query

# Raises InvalidParameter — wrong case is caught here, not silently at the endpoint
Query("atlas", sort="Size")

# Raises UnknownParameter — the closest real name is suggested
Query("atlas", searh_query="atlas")

# Raises DeepPagingError — page × per_page = 10,200 > 10,000
Query("atlas", page=102, per_page=100)
```

## Constructor

```python
Query(query: str | None = None, **params: Any) -> Query
```

The first positional argument is the free-text search term. It maps to the `search_query` wire parameter (the alias `query` is handled transparently). All other parameters are keyword arguments using the endpoint's own parameter names. Parameters set to `None` are dropped before validation, so sparse dicts build cleanly:

```python
from meawfy import Query

# Basic query
q = Query("periodic table", providers=["mega", "dropbox"], sort="size", order="desc")

# From a sparse dict — None values are dropped automatically
filters = {"max_size": "500mb", "ext": None, "sort": "indexed"}
q = Query("worksheet", **{k: v for k, v in filters.items() if v is not None})

# Size accepts bytes or a human suffix
q = Query("atlas", min_size="10mb", max_size="1.5gb")

# Providers as a list or comma string — both are valid
q = Query("atlas", providers="mega,dropbox")
q = Query("atlas", providers=["mega", "dropbox"])
```

Validation runs immediately. `InvalidParameter` is raised for bad values, `UnknownParameter` for names outside the 50-name registry, and `DeepPagingError` when `page × per_page` exceeds 10,000.

<Note>
The alias `query` is client-side only. On the wire, the parameter is always `search_query`. The `Query` class accepts both names but always emits `search_query`.
</Note>

## Properties and methods

### `params`

```python
@property
def params(self) -> dict[str, str]
```

Returns the validated wire values in registry order — the same order the endpoint expects. Every value is a string, normalised to the form the endpoint uses (e.g. sizes converted to byte counts, dates normalised to `YYYY-MM-DD`, enum values lowercased).

```python
q = Query("periodic table", providers=["mega", "dropbox"], min_size="10mb", per_page=50)
print(q.params)
# {'search_query': 'periodic table', 'providers': 'mega,dropbox',
#  'min_size': '10000000', 'per_page': '50'}
```

### `pairs()`

```python
def pairs(self) -> list[tuple[str, str]]
```

Returns the validated parameters as a list of `(name, value)` tuples, in registry order. This is the form `urlencode` consumes, and what `echo_report()` compares against the response.

```python
q = Query("atlas", sort="size", order="desc")
print(q.pairs())
# [('search_query', 'atlas'), ('sort', 'size'), ('order', 'desc')]
```

### `query_string()`

```python
def query_string(self) -> str
```

Returns the URL-encoded query string. Spaces become `+` and a literal `+` becomes `%2B`, matching what the endpoint's tokenizer expects (trap 4 from the handbook). Parameters appear in registry order, so two `Query` objects built from the same values always produce identical strings.

```python
q = Query("periodic table", providers=["mega", "dropbox"], min_files=20,
          sort="size", order="desc", per_page=50, page=1)
print(q.query_string())
# 'search_query=periodic+table&providers=mega%2Cdropbox&min_files=20&sort=size&order=desc&page=1&per_page=50'
```

### `url(base_url)`

```python
def url(self, base_url: str) -> str
```

Joins the query string onto a base URL. If the base already contains a `?`, it appends with `&`; otherwise it uses `?`.

```python
from meawfy import Query

BASE = "https://meawfy.com/internal/api/results.json"
q = Query("atlas", providers="mega", sort="size", order="desc")
print(q.url(BASE))
# https://meawfy.com/internal/api/results.json?search_query=atlas&providers=mega&sort=size&order=desc
```

### `copy(**overrides)`

```python
def copy(self, **overrides: Any) -> Query
```

Returns a new `Query` with some values replaced. Setting an override to `None` removes that parameter from the copy. The original `Query` is never modified. This is the standard pattern for page-by-page iteration.

```python
from meawfy import MeawfyClient, Query

client = MeawfyClient()

# Build the base query once; iterate pages by copying
base = Query("periodic table", providers="mega", sort="size", order="desc", per_page=50)

page = 1
while True:
    q = base.copy(page=page)
    envelope = client.search(q)
    for result in envelope.results:
        print(result.name, result.human_size)
    if page >= envelope.pages:
        break
    page += 1
```

<Warning>
`page × per_page` must not exceed 10,000. If a `copy()` call would push the product past the cap, `DeepPagingError` is raised on construction of the copy, before any network call.
</Warning>

### `advice`

```python
@property
def advice(self) -> tuple[str, ...]
```

A tuple of advisory strings (not a list) describing parameter combinations that are valid but likely to mislead. Advice is computed once at construction time. An empty tuple means the parameter set has no known traps.

```python
from meawfy import Query

q = Query("atlas", sort="size")          # sort=size on folders sorts unknowns last
print(q.advice)
# ("sort=size: folders with an unknown total sort last in both directions; "
#  "kind=file is the comparison you probably meant",)

q2 = Query("atlas", providers="pixeldrain")
print(q2.advice)
# ("pixeldrain: undocumented host(s) that answer today. Their rows are thinner "
#  "than a MEGA row and the url comes back already unlocked, ...",)
```

The advice system fires on these conditions:

<Accordion title="Complete list of advice triggers">

| Trigger | Advisory message |
|---|---|
| No `search_query` or `q` | Browsing the whole index rather than searching |
| `order` set without `sort` | `order` has no effect without an explicit sort key |
| `sort=relevance` with `order` | `relevance` is always best-first; `order` is ignored |
| `sort=files` without `kind=folder` | `files` field is null on file rows |
| `sort=size` without `kind=file` | Folders with an unknown total sort last in both directions |
| `alive=false` without `checked_after` | Dead rows are purged 72 hours after detection |
| `preview_size` without `preview=1` | `preview_size` only affects the CDN path; no preview object is returned |
| `has_preview=true` without `preview=1` | Selects rows with a preview but does not return the object |
| `sort=has_preview` without `preview=1` | Sort key is meaningless without the preview object |
| `preview=1` with `fields` that omits `preview` | The projection drops the field you requested |
| `id` with other parameters | `id` bypasses tokenisation; every other parameter can only narrow a one-row result |
| `hash` with `providers` or `provider` | `hash` returns rows across all providers; a provider filter can only narrow that |
| Any experimental provider | Rows from undocumented hosts are thinner; the index makes no guarantee they stay |
| `duration` without `ext` | Duration is only indexed where the indexer extracted it |
| `page_count` without `ext` | Page count is only indexed where the indexer extracted it |
| `folder_path` starting with `*` | Substring match rather than exact path match |
| Any `planned` or `reserved` parameter | The index does not guarantee it will honour the parameter |

</Accordion>

### `echo_report(echo)`

```python
def echo_report(self, echo: Mapping[str, Any]) -> EchoReport
```

A convenience wrapper around `EchoReport.from_pairs()`. Accepts any `Mapping[str, Any]` — typically `envelope.query`, the dict the endpoint echoed back. Compares the query's sent values against the echoed values. On an endpoint that answers `200` to everything, the echo is the primary debugging signal: a parameter missing from it did nothing.

```python
from meawfy import MeawfyClient, Query

client = MeawfyClient()
q = Query("worksheet", min_mirrors=2, sort="indexed", order="asc")
envelope = client.search(q)

report = q.echo_report(envelope.query)   # or: envelope.echo_report(q)
print(report.summary())
# "echo confirms 4/4 parameter(s)"  — if all were honoured
# "echo confirms 3/4 · absent from echo: min_mirrors"  — if one was dropped
```

<Tip>
`Envelope.echo_report(query)` is equivalent and saves a step. Both paths call `EchoReport.from_pairs` with the same data.
</Tip>

## Class method: `Query.coerce()`

```python
@classmethod
def coerce(cls, value: Query | Mapping[str, Any] | str | None, **params: Any) -> Query
```

A factory that accepts a `Query`, a mapping, a string, or `None`, plus optional keyword overrides. Useful when a helper function should accept whatever the caller has at hand.

<Tabs>
  <Tab title="From a Query">
    ```python
    from meawfy import Query

    q = Query("atlas", sort="size")
    # Returns q unchanged — no copy, no revalidation
    same = Query.coerce(q)
    assert same is q

    # Extra params raise InvalidParameter when a Query is passed
    # (ambiguous: the Query is already validated)
    ```
  </Tab>
  <Tab title="From a mapping">
    ```python
    from meawfy import Query

    params = {"search_query": "atlas", "sort": "size", "order": "desc"}
    q = Query.coerce(params, per_page=50)   # merges keyword overrides
    ```
  </Tab>
  <Tab title="From None">
    ```python
    from meawfy import Query

    # None + keyword params builds a Query with only those params
    q = Query.coerce(None, search_query="atlas", providers="mega")
    ```
  </Tab>
  <Tab title="From a string">
    ```python
    from meawfy import Query

    # A bare string is treated as the search term
    q = Query.coerce("periodic table", providers="dropbox", sort="indexed")
    ```
  </Tab>
</Tabs>

<Warning>
Passing a `Query` together with extra keyword arguments raises `InvalidParameter`. The `Query` is already validated and complete; merging would require revalidation with ambiguous precedence.
</Warning>

## Validation behaviour

`Query` validates every value at construction time and raises before any network call:

<CardGroup cols={2}>
  <Card title="InvalidParameter" icon="circle-xmark">
    A value that is in the 50-name registry but fails type, range, or cross-check validation. Examples: `sort="Size"` (wrong case), `min_size=500` with `max_size=100` (inverted range), `per_page=200` (above the cap of 100), `search_query` longer than 200 characters.
  </Card>
  <Card title="UnknownParameter" icon="question">
    A keyword argument whose name is not one of the 50 documented parameter names. The error message includes the closest known name as a hint.
  </Card>
  <Card title="DeepPagingError" icon="layer-group">
    A subclass of `InvalidParameter`. Raised when `page × per_page > 10,000`. The endpoint would continue answering with the cap silently applied; the client refuses before the request goes out.
  </Card>
  <Card title="Cross-checks" icon="arrows-left-right">
    Range pairs are validated together: `min_size > max_size`, `after > before`, and `created_after > created_before` all raise `InvalidParameter` even when each individual value is well-formed.
  </Card>
</CardGroup>

```python
from meawfy import Query, InvalidParameter, UnknownParameter, DeepPagingError

try:
    Query("atlas", sort="Size")          # wrong case
except InvalidParameter as exc:
    print(exc.name, exc.value, exc.reason)
    # sort 'Size' expected one of: relevance, size, files, name, ...

try:
    Query("atlas", searh_query="atlas")  # typo
except UnknownParameter as exc:
    print(exc.names)                     # ('searh_query',)

try:
    Query("atlas", page=200, per_page=100)
except DeepPagingError as exc:
    print(exc)                           # page x per_page = 20000 leaves the reachable window
```

## Iterating pages with `copy()`

`copy()` is the idiomatic way to walk pages. Build the base query once with the stable parameters, then copy with an incremented `page` on each iteration. The full example below uses `MeawfyClient.iterate()`, but the underlying pattern is `copy()`:

```python
from meawfy import MeawfyClient, Query

client = MeawfyClient()

base = Query(
    "periodic table",
    providers=["mega", "dropbox"],
    sort="size",
    order="desc",
    per_page=100,
    fields="id,name,provider,size,url",
)

# Emit any advice before the first request
for note in base.advice:
    print(f"advice: {note}")

results = []
page = 1
while True:
    envelope = client.search(base.copy(page=page))
    results.extend(envelope.results)
    if page >= envelope.pages or page * 100 >= 10_000:
        break
    page += 1

print(f"collected {len(results)} rows across {page} page(s)")
```

<Tip>
`MeawfyClient.collect(query)` wraps this pattern and sets `Collection.truncated` when the 10,000-row cap is hit. Use it when you want all rows without managing page state manually.
</Tip>

## `__repr__` and `__str__`

```python
q = Query("periodic table", sort="size")
repr(q)   # "<Query 'search_query=periodic+table&sort=size'>"
str(q)    # "search_query=periodic+table&sort=size"
```

Both forms use the URL-encoded query string, making a `Query` easy to inspect in a debugger or log.
