The transport layer separates the concern of making an HTTP request from the concern of interpreting the response. `MeawfyClient` calls a single callable of type `Transport` — any function that takes a URL string and returns a `TransportResponse`. The default implementation uses Python's `urllib`, but you can swap it for a replay fixture, a mock, or a wrapper around any HTTP library without touching the client logic.

```python
from meawfy import MeawfyClient, replay_transport

# Default transport: live urllib requests
client = MeawfyClient()

# Replay transport: every request gets the same recorded response
client = MeawfyClient(transport=replay_transport("fixtures/results.json"))
```

---

## `Transport` type alias

```python
Transport = Callable[[str], TransportResponse]
```

A `Transport` is any callable that accepts a single URL string and returns a `TransportResponse`. The URL is the fully-constructed query string URL built by the client — the transport's only job is to fetch it and wrap the result.

The protocol has two failure modes:
- Raise `RateLimited` for an HTTP 429 response.
- Raise `TransportError` for any other non-JSON or non-200 response.

Any other exception propagates through the client unhandled.

---

## `TransportResponse`

```python
@dataclass(frozen=True)
class TransportResponse:
    status:  int
    payload: dict[str, Any]
    headers: Mapping[str, str]
```

The three things a transport hands back to the client.

<ResponseField name="status" type="int">
  The HTTP status code. The Meawfy endpoint sends `200` for almost every request, including error responses — the client inspects `payload` for a body-level `error` object regardless of this field.
</ResponseField>

<ResponseField name="payload" type="dict[str, Any]">
  The parsed JSON body. The transport is responsible for decoding the response bytes as UTF-8 and parsing the JSON. If the body is not valid JSON or not a JSON object, the transport must raise `TransportError` rather than returning a malformed `TransportResponse`.
</ResponseField>

<ResponseField name="headers" type="Mapping[str, str]">
  Response headers as a case-insensitive-compatible mapping. The client reads `x-ratelimit-remaining` (for the rate limiter) and `retry-after` (for 429 handling) from this mapping; both header names are normalised to lowercase by the built-in transport. Custom transports should lowercase their header names for compatibility.
</ResponseField>

## `urllib_transport`

```python
def urllib_transport(
    url: str,
    *,
    timeout: float = 15.0,
    headers: Mapping[str, str] | None = None,
) -> TransportResponse:
```

The default transport. Issues `GET url` using `urllib.request.urlopen` and returns the decoded body. All request headers (including `User-Agent` and `Accept`) are passed in via the `headers` argument by the client's `_default_transport` factory — the transport itself does not add any.

**Raises**
- `RateLimited` — HTTP 429. `retry_after` is parsed from the `Retry-After` header in either seconds or HTTP-date form.
- `TransportError` — any HTTP error other than 429 (including 5xx). `exc.status` carries the status code; `exc.payload` carries the parsed body if the response body was valid JSON.
- `TransportError` — `URLError` (DNS failure, connection refused, TLS error). `exc.status` is `None`.
- `TransportError` — `TimeoutError`. `exc.status` is `None`.

```python
from meawfy import urllib_transport, TransportResponse

# Call directly for one-off use (bypasses rate limiting and retries)
response: TransportResponse = urllib_transport(
    "https://meawfy.com/internal/api/results.json?search_query=test",
    timeout=10.0,
    headers={"User-Agent": "my-script/1.0", "Accept": "application/json"},
)
print(response.status)   # 200
print(response.payload)  # {"results": [...], "total": ..., "query": {...}}
```

<Note>
`urllib_transport` is a free function, not a method. `MeawfyClient` does not call it directly — instead, `_default_transport()` wraps it in a closure that captures the configured `timeout` and `headers`. This means swapping the transport via `transport=` replaces the closure entirely.
</Note>

## `replay_transport`

```python
def replay_transport(
    source: Mapping[str, Any] | str | Path
) -> Transport:
```

Returns a `Transport` that answers every request with the same pre-recorded envelope body, ignoring the URL entirely. Useful for offline development, CI fixtures, and regression tests that need stable response data.

The endpoint is internal and unversioned — no announcement marks a renamed parameter or a changed response shape. `replay_transport` is the handbook's recommended mechanism for pinning the day you last tested it: record one real response with `MeawfyClient.save_envelope`, commit the file, and serve it back here.

<ParamField path="source" type="Mapping | str | Path">
  The recorded response body. Three forms are accepted:
  - A file path (`str` or `pathlib.Path`): read and parsed as UTF-8 JSON on construction. The file must be a JSON object (the raw envelope body, not a list).
  - A `Mapping` (e.g. a `dict`): deep-copied on construction so mutations to the original do not affect the transport.
</ParamField>

**Returns** `Transport` — a callable `(url: str) -> TransportResponse`.

Every call to the returned transport returns a fresh deep copy of the payload alongside a fixed `{"x-ratelimit-remaining": "120"}` header. The `echo_report` returned by any search using a replay transport reflects the frozen body's `query` object, not the URL you called — this is intentional and is what the handbook means by "pin the date you last tested it".

```python
from pathlib import Path
from meawfy import MeawfyClient, replay_transport

# From a file recorded earlier with save_envelope
transport = replay_transport("fixtures/periodic-table.json")
client = MeawfyClient(transport=transport)
env = client.search("periodic table")   # no network call

# From a Path object
transport = replay_transport(Path("fixtures") / "results.json")

# From a dict (useful in unit tests)
transport = replay_transport({
    "results": [{"id": "mega:abc1", "name": "atlas.pdf", "provider": "mega"}],
    "total": 1,
    "page": 1,
    "per_page": 24,
    "pages": 1,
    "took_ms": 5,
    "query": {"search_query": "atlas"},
})
```

<Tip>
Set `MEAWFY_FIXTURE=/path/to/fixture.json` in the environment before constructing a `MeawfyClient()`. If that variable is set, the client creates a `replay_transport` automatically — no code change is needed. This is the simplest way to make a test suite or a CI job work offline.
</Tip>

## `resolve_base_url`

```python
def resolve_base_url(base_url: str | None = None) -> str:
```

Normalises the endpoint URL so that `MeawfyClient` and custom code both accept the same range of inputs. Three forms are accepted:

- Full endpoint URL: `https://meawfy.com/internal/api/results.json` — returned as-is.
- Host-only: `meawfy.com` (no `://`) — `https://` and `/internal/api/results.json` are appended.
- `None` — reads `MEAWFY_BASE_URL` from the environment; if that variable is also unset, returns the production endpoint `https://meawfy.com/internal/api/results.json`.

```python
from meawfy import resolve_base_url

resolve_base_url(None)
# "https://meawfy.com/internal/api/results.json"

resolve_base_url("meawfy.com")
# "https://meawfy.com/internal/api/results.json"

resolve_base_url("https://meawfy.com/internal/api/results.json")
# "https://meawfy.com/internal/api/results.json"

# With environment variable:
import os
os.environ["MEAWFY_BASE_URL"] = "https://staging.meawfy.com"
resolve_base_url(None)
# "https://staging.meawfy.com/internal/api/results.json"
```

## `RateLimiter`

```python
class RateLimiter:
    def __init__(
        self,
        limit: int = 120,
        window: float = 60.0,
        *,
        clock: Callable[[], float] = time.monotonic,
        sleep: Callable[[float], None] = time.sleep,
    ) -> None:
```

A sliding-window throttle that paces outgoing requests so the documented 120-requests-per-minute limit is rarely reached. `MeawfyClient` creates one internally using the `requests_per_minute` constructor argument; you do not normally instantiate `RateLimiter` directly.

The limiter tracks a deque of timestamps for the last `limit` requests in the last `window` seconds. When the window is full, `acquire()` sleeps until the oldest timestamp ages out. When the endpoint returns a 429, the client calls `block()` with the `Retry-After` value, which sets a hard floor below which no new request can start.

<ParamField path="limit" type="int" default="120">
  Maximum requests in one `window`. The default is the endpoint's documented limit.
</ParamField>

<ParamField path="window" type="float" default="60.0">
  The sliding window duration in seconds.
</ParamField>

<ParamField path="clock" type="Callable[[], float]" default="time.monotonic">
  A callable returning the current time. Swap for a deterministic counter in tests.
</ParamField>

<ParamField path="sleep" type="Callable[[float], None]" default="time.sleep">
  A callable for sleeping. The same `sleep` argument passed to `MeawfyClient` is forwarded here.
</ParamField>

### `acquire()`

```python
def acquire(self) -> None:
```

Claims one request slot, sleeping if necessary until a slot is available. The client calls `acquire()` before every transport call. If `block()` has been called (e.g. after a 429), `acquire()` waits until the blocked period has elapsed before checking the sliding window.

### `observe(headers)`

```python
def observe(self, headers: Mapping[str, str]) -> int | None:
```

Reads `X-RateLimit-Remaining` from the response headers and stores it as `self.remaining`. Called automatically by the client after every successful response. Returns the integer value, or `None` if the header is absent or unparseable.

### `block(seconds)`

```python
def block(self, seconds: float) -> None:
```

Sets a hard floor: no request may start until at least `seconds` seconds from now. The client calls this after a 429 with the `Retry-After` value before sleeping. Multiple calls keep the highest floor.

### Properties and attributes

<ResponseField name="remaining" type="int | None">
  The last `X-RateLimit-Remaining` value recorded by `observe()`. Also exposed on `MeawfyClient` as `client.remaining`.
</ResponseField>

<ResponseField name="waits" type="int">
  Cumulative number of times `acquire()` had to sleep. Useful in tests to confirm the pacing logic was exercised.
</ResponseField>

## Writing a custom transport

A custom transport is any callable that takes a URL string and returns a `TransportResponse`. The minimal contract:

1. Issue a `GET` request to the URL.
2. Parse the response body as JSON.
3. Return `TransportResponse(status, payload, headers)` on success.
4. Raise `RateLimited(retry_after=seconds)` for HTTP 429.
5. Raise `TransportError(message, status=code)` for other HTTP errors or JSON decode failures.

```python
from collections.abc import Mapping
from typing import Any
from meawfy import TransportResponse
from meawfy.errors import RateLimited, TransportError


def my_transport(url: str) -> TransportResponse:
    import http.client, json, urllib.parse

    parsed = urllib.parse.urlparse(url)
    conn = http.client.HTTPSConnection(parsed.netloc, timeout=15)
    conn.request("GET", parsed.path + "?" + (parsed.query or ""))
    resp = conn.getresponse()
    body = resp.read()

    try:
        payload = json.loads(body.decode("utf-8"))
        if not isinstance(payload, dict):
            raise TransportError(f"{url} returned a non-object JSON value")
    except json.JSONDecodeError as exc:
        raise TransportError(f"{url} did not return JSON: {exc}") from None

    headers = {k.lower(): v for k, v in resp.getheaders()}

    if resp.status == 429:
        raw = headers.get("retry-after")
        retry_after = float(raw) if raw and raw.strip().isdigit() else None
        raise RateLimited(retry_after=retry_after, payload=payload)

    if resp.status >= 400:
        raise TransportError(
            f"HTTP {resp.status} for {url}", status=resp.status, payload=payload
        )

    return TransportResponse(status=resp.status, payload=payload, headers=headers)


client = MeawfyClient(transport=my_transport)
```

<Warning>
A custom transport that raises any exception other than `TransportError` (or its subclass `RateLimited`) will propagate out of `MeawfyClient.search` unhandled — the retry logic only catches `TransportError`. Wrap unexpected errors in `TransportError` to let the retry policy decide what to do with them.
</Warning>

## Custom transport for testing

The following pattern creates a transport that replays a sequence of responses, useful for testing retry logic.

```python
from meawfy import MeawfyClient, RetryPolicy, TransportResponse
from meawfy.errors import TransportError, RateLimited


def make_sequence_transport(*responses):
    """Returns each TransportResponse (or raises each exception) in order."""
    queue = list(responses)

    def transport(url: str) -> TransportResponse:
        item = queue.pop(0)
        if isinstance(item, BaseException):
            raise item
        return item

    return transport


# Simulate: 503, then 429 with 5-second window, then success
transport = make_sequence_transport(
    TransportError("503 Service Unavailable", status=503),
    RateLimited(retry_after=5.0),
    TransportResponse(
        status=200,
        payload={
            "results": [], "total": 0, "page": 1,
            "per_page": 24, "pages": 0, "took_ms": 2,
            "query": {"search_query": "test"},
        },
        headers={"x-ratelimit-remaining": "100"},
    ),
)

waited: list[float] = []
policy = RetryPolicy(max_attempts=4, jitter=0.0, rand=lambda: 0.0)
client = MeawfyClient(
    transport=transport,
    sleep=waited.append,  # record waits instead of sleeping
    retry=policy,
)

env = client.search("test")
assert env.total == 0
assert client.stats["attempts"] == 3
assert client.stats["retries"] == 2
print(f"waits: {waited}")  # [0.5, 5.0]
```

## Environment variables

The transport layer reads three environment variables during construction:

| Variable | Purpose | Default |
|----------|---------|---------|
| `MEAWFY_BASE_URL` | The endpoint URL (passed through `resolve_base_url`) | `https://meawfy.com/internal/api/results.json` |
| `MEAWFY_TIMEOUT` | Per-request socket timeout in seconds | `15` |
| `MEAWFY_FIXTURE` | Path to a JSON file served by `replay_transport` instead of making live requests | unset |

<Info>
`MEAWFY_FIXTURE` is checked in `_default_transport()` at construction time, not at call time. Changing the environment variable after constructing a `MeawfyClient` has no effect on that instance. To change the fixture at runtime, pass a new `replay_transport(path)` via `transport=`.
</Info>
